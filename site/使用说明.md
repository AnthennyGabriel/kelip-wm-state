# 世界模型 · 原图交互学习版

打开 `index.html`，或运行 `node serve.cjs` 后访问 http://127.0.0.1:8765/ 。所有文件及 chapters 文件夹需要保存在一起。

## 两个独立入口

**发展综述**：保留可lip公开资料的四章、144页原始展示。完整路线逐页浏览；“开始综述汇报”选取43页串起研究发展。首页的四个分析入口分别讨论技术路线、功能模块、能力层级、瓶颈与趋势。

**模块学习库**：打开 `library.html`。按四条讲解脉络组织24项代表工作，展开论文可见一级模块与二级知识点；也可切换到功能模块浏览或搜索。共有85个专题入口，包含24项工作和61个基础或机制模块。四组是汇报脉络，可互相交叉，并非互斥的架构分类。LeWM条目为补充知识，没有独立原图。

## 原图怎样讲

论文主图、文字和版式保留在原来的位置。36张关键论文图片添加了人工定位的模块区域；原始网页中的结构图和时间线也有对应入口。64页含可点击标注，共466个模块入口。实验结果、引言、总结等其他页面按原有内容块逐步突出，不添加虚构的网络连接。

点击“播放”后，每3.8秒推进一步；也可以手动推进。并行分支同时突出，已标注的反馈路径沿原图显示。作者已有的两处分步动画继续使用其原动画。进入页面默认暂停，便于演讲者控制节奏。支持系统的减少动态效果设置。

交互路径：**原图模块 → 简短讲解小窗 → 深入讲解 → 子模块专题 → 返回原页**。返回时恢复原页码及步骤，保持暂停。小窗不会立即把人带离主线。学习库和专题页都保留返回原图的入口。手机端另有较大的本页模块按钮，方便打开小窗。

VAE、MPC、Diffusion Policy采用各自的结构示意与交互实验：

- VAE：调整均值、标准差，观察潜变量样本及KL。
- MPC：比较候选计划、只执行首步、加入环境扰动后重新规划。实验使用穷举，未运行CEM。
- Diffusion Policy：拖动去噪进度，比较两种动作模式。曲线是概念插值，未运行神经网络。

其他专题提供输入输出、原理、训练与推理区别、边界、下层知识点及相关原页资料。模块目录表示学习结构或依赖知识；真实信息流以论文原图为准。

## 操作

| 操作 | 作用 |
|---|---|
| 鼠标滚轮向下 / 向上 | 下一页 / 上一页；目录和小窗内保持普通滚动 |
| ← / →、空格 | 翻页 |
| J / K | 下一步 / 上一步 |
| P | 播放 / 暂停 |
| R | 从第一步重播 |
| 点击图中标注或手机模块按钮 | 简短讲解小窗 |
| 隐藏标注 | 查看无交互标注的原页 |
| D | 本页逐层解读 |
| G | 搜索目录并跳页 |
| F | 放映模式 |
| Esc | 关闭小窗、解读或放映模式 |
| Home / End | 当前路线首尾页 |

每次打开目录，当前页会自动高亮并定位到列表中间；首尾页也能居中显示。滚轮翻页按一次连续滚动处理，避免惯性造成连跳。
