# 模块讲解的文献与证据规范

模块页服务于论文阅读。机制解释需要沿概念基础、具体工作与实验依据展开；文字长度本身不能代表证据强度。

## 每个完整专题需要的内容

1. **定义和来源**：概念的准确含义、采用的基础文献；区分一般概念与具体论文贡献，避免把一种实现称为唯一来源。
2. **问题和假设**：为什么需要这个模块，能看到什么信息，依赖什么假设。
3. **数学和接口**：时间索引、符号、分布与张量含义；注明公式是原式、等价改写还是教学简化。
4. **训练**：样本构造、监督来源、目标函数、参数更新与停止梯度位置。
5. **推理**：部署可用条件、状态更新与执行接口，逐项排除未来信息泄露。
6. **跨工作差异**：对照世界模型论文的实际实现，解释同名模块的不同职责。
7. **图和证据**：附来源、版本或章节定位、图中节点与箭头解释；区分论文图、裁图、作者标注和本站示意。
8. **实验和边界**：任务、数据、评测协议、消融、局限；没有核实的数字不作为已确认结论。
9. **理解自检**：要求解释原因、信息流或失败情形，给出有依据的答案。

## 材料层级

- 原论文、官方代码与作者项目页是主要核查入口。
- 可lip配套调研笔记保留原作者措辞、估读与未核实标记，作为二手阅读材料。
- 本站机制解释与交互实验单独标明；概念实验不构成论文复现。
- 关键词检索到的笔记段落提供定位便利，不自动升级为原文已核验事实。
